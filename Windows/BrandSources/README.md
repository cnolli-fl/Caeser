# Arte original do Windows

Cópias exatas da marca aprovada para o Windows 2.2.1, antes da nova identidade do Mac 3.1.0. O aplicativo e a geração do ICO usam estas fontes para que mudanças no tema do Mac não alterem a edição Windows.

As fontes anteriores ficam preservadas nesta pasta. A partir da 2.3.0, `Ocean/` contém cópias independentes da identidade azul aprovada no Mac: nota branca e PNGs originais, sem redesenho. A suíte protege seu SHA-256 e o vínculo independente da edição Windows. Os PNGs do ícone são convertidos em ICO por `Windows/Scripts/PrepareAssets.mjs`.
